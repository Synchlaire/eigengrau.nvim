# Feature Requirements

## AI Capabilities
*   **Chat Interface:** Sidebar/Floating window to query LLMs about code/general topics.
*   **Inline Editing:** "Diff" view or inline replacement for refactoring code blocks.
*   **Context Awareness:** Ability to reference open buffers, specific files, or visual selections in prompts.
*   **Slash Commands:** Quick actions like `/commit`, `/explain`, `/fix`.

## Obsidian Integration
*   **Vault Navigation:** `gf` to follow wiki-links `[[Note]]`.
*   **Daily Notes:** One-key open/create today's note.
*   **Templates:** Insert standardized templates for new notes.
*   **Search:** Telescope/Fzf picker for notes by title or content.
*   **Images:** Paste image from clipboard -> save to vault -> insert markdown link.

## "Fast Editing"
*   **LSP:** Go to definition, Find references, Hover documentation.
*   **Diagnostics:** Inline error/warning display (virtual text).
*   **Formatting:** Format on save (async).
*   **Linting:** Real-time analysis (e.g., ShellCheck for bash).
